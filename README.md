FinSmart - Personal Finance Tracker
FinSmart is a free, privacy-focused, and fully client-side web application for personal financial management. Built entirely with vanilla HTML, CSS, and JavaScript, it allows users to track income and expenses, set budgets, calculate financial goals, and visualize spending patterns, all without creating an account or sharing data with any server.

Key Features
Core Finance Tracking:
Transaction Management: Add, categorize, and filter income/expense entries

Real-time Summary: Automatic calculation of total income, expenses, and balance

Budget System: Set monthly budgets with visual progress indicators

Category Breakdown: Expense distribution visualization using Chart.js

Financial Calculators:
Debt Payoff Calculator: Estimate time and interest for debt repayment

Savings Goal Calculator: Plan and track progress toward savings targets

Mortgage Calculator: Calculate monthly payments and total interest

Privacy & Security:
100% Client-Side: All data stored locally in your browser (localStorage)

No Registration: No accounts, no passwords, no email collection

Export Options: Download data as JSON or CSV for backup

Complete Control: Clear all data with one click

User Experience:
Responsive Design: Works seamlessly on desktop and mobile devices

Smooth Animations: CSS transitions and smooth scrolling navigation

Interactive Charts: Visual expense breakdown with hover details

Intuitive UI: Clean, modern interface with clear visual feedback
